# Workflow: تجهيز موجز إعلاني لمنتج مرشّح

**Responsibilities** — هذا الـ workflow يملك اختيار المنتجات الأنسب للإعلان بناءً على مبيعات حقيقية، وتجهيز موجز حملة (عنوان، نص، ميزانية مقترحة) كمسودة جاهزة للمراجعة. لا يملك نشر أو تشغيل أي حملة فعلية أو صرف أي ميزانية — تلك خطوة منفصلة تتطلب موافقة ADMIN صريحة.

**What starts it** — طلب من فريق التسويق (عبر محادثة مع الوكيل)، عادة أسبوعيًا أو قبل مناسبة/موسم بيع، أو عند ملاحظة تباطؤ في مبيعات فئة معيّنة.

**How it runs**
1. يستدعي الوكيل `marketing.suggestAdCandidates` (وهي READ) لتحليل بيانات المبيعات الفعلية من سلة عبر `salla.analytics.salesSummary` وترشيح المنتجات الأعلى مبيعًا كمرشّحين طبيعيين للإعلان.
2. يعرض الوكيل المرشّحين للمستخدم مع سبب الترشيح (الأعلى مبيعًا خلال الفترة المحلَّلة)، ويطلب تأكيد أي منتج للمتابعة به.
3. بعد التأكيد، يستدعي `marketing.prepareCampaignBrief` (وهي DRAFT) لإنشاء `CampaignDraft` يتضمن: القناة (إنستغرام/تيك توك/سناب شات/يوتيوب)، العنوان، نص الإعلان، والميزانية المقترحة بالريال السعودي.
4. تُحفظ المسودة بحالة أولية ولا تُرسل أو تُنشر لأي منصة إعلانية بعد.
5. تراجَع المسودة من موظف تسويق ADMIN؛ إذا رغب بتشغيلها فعليًا، يُستدعى `marketing.launchCampaign` (ACTION) صراحة — وتصبح تلقائيًا "بانتظار الموافقة" في النظام قبل أي تشغيل فعلي، وتبدأ افتراضيًا بحالة PAUSED للأمان.
6. عند الموافقة، تُنفَّذ الحملة فعليًا على المنصة المختارة (ميتا/تيك توك/سناب شات) وتُحدَّث حالة المسودة إلى `launched`، ويُسجَّل كل شيء في `AuditLog`.

**What success looks like**
- المعيار: كل موجز حملة مبني على بيانات مبيعات فعلية (ليس تخمينًا)، ولا تُصرف أي ميزانية أو يُنشر أي إعلان دون موافقة ADMIN موثّقة.
- مثال جيد: موجز حملة لفستان سجّل أعلى كمية مبيعات آخر 30 يومًا حسب `salesSummary`، بنص إعلاني يعكس مميزاته الفعلية، وميزانية يومية معقولة، بحالة PAUSED بانتظار المراجعة.
- مثال سيئ: اختيار منتج للإعلان بدون تحليل مبيعات فعلي ("شكله حلو")، أو استدعاء `marketing.launchCampaign` مباشرة بحالة ACTIVE دون مرور بمسودة ومراجعة.

**Access needed**
- Salla Admin API v2 (بيانات المبيعات الحقيقية عبر `salla.analytics.salesSummary`).
- حسابات إعلانية مُهيّأة عبر متغيرات البيئة: Meta Marketing API (إنستغرام/فيسبوك)، TikTok Ads API، Snapchat Marketing API، ومفتاح YouTube Data API لتحليل الاتجاهات.
- لوحة تحكم FARA لمراجعة `CampaignDraft` والموافقة على التشغيل الفعلي.
