# WhatsApp Agent — Manual QA Checklist

These are the 17 test messages from the original spec. **This is a manual review checklist, not automated test output** — this sandbox has no network access to the Anthropic API or a running `apps/api` instance, so nothing here has actually been run against the live agent. Whoever has `ANTHROPIC_API_KEY` and Salla credentials configured should run each message through `POST /api/conversations/:id/chat` (or the dashboard chat) and confirm the reply matches `support/knowledge/whatsapp-policy.md` before treating this as done.

| # | رسالة العميل | يجب أن يتحقق الرد من |
|---|---|---|
| 1 | السلام عليكم | تحية بأسلوب FARA المعتمد (قسم 1) |
| 2 | أين يقع متجرك؟ | جدة + توصيل لكل المملكة (قسم 1) |
| 3 | هل لديك موقع ويب؟ | https://fara-sa.com (قسم 5) |
| 4 | ما الذي تبيعه؟ | فساتين/أزياء نسائية — بدون اختراع تفاصيل منتج غير مطلوبة |
| 5 | ما هي سياسة الاستبدال والاسترجاع؟ | نص السياسة المعتمد حرفيًا (قسم 2) — استبدال فقط، استرجاع غير متوفر |
| 6 | هل لديكم توصيل؟ | مدد الشحن الصحيحة داخليًا/دوليًا وشركات الشحن (قسم 3) |
| 7 | أقدر أغير المقاس بعد الطلب؟ | يُعامل كاستبدال، شرط نفس يوم الاستلام + رسوم 50 ريال (قسم 2) |
| 8 | هل فيه دفع عند الاستلام؟ | نعم، داخل السعودية فقط (قسم 4) |
| 9 | كيف أستخدم كود الخصم؟ | F1، خانة الكود ثم تطبيق — بدون اختراع نسبة خصم (قسم 6) |
| 10 | أقدر أطلب بالواتساب؟ | نعم، أو عبر الموقع — خطوات الطلب (قسم 5) |
| 11 | كيف أتتبع طلبي؟ | طلب رقم الطلب/التتبع، ثم استعلام سلة الفعلي — بدون اختراع حالة (قسم 7) |
| 12 | أبي مقاس أكبر من اللي وصلني | تحقق من يوم الاستلام + حالة الفستان + توفر المقاس عبر سلة، ثم رسوم الاستبدال (قسم 2) |
| 13 | أقدر أبدل الفستان بلون ثاني؟ | يُعامل كاستبدال بنفس شروط قسم 2، تحقق من توفر اللون |
| 14 | لو الفستان فيه عيب وش أسوي؟ | طلب صورة + رقم الطلب، بدون وعد تلقائي (قسم 9) |
| 15 | هل الاسترجاع مسموح؟ | لا، غير متوفر (قسم 2) |
| 16 | لو مر يوم كامل أقدر أبدل؟ | لا — الاستبدال في نفس يوم الاستلام فقط (قسم 2) |
| 17 | كم ياخذ وقت وصول البديل؟ | حسب مدة الشحن الفعلية (قسم 3)، بدون اختراع رقم مختلف |
| 18 | المندوب أرسل لي بوليصة إرجاع، وش أسوي؟ | تحقق من رقم/حالة الطلب وطريقة الدفع، وتصعيد لموظف إن كانت الحالة تخص تابي/تمارا (قسم 10 و11) |

كل رد يُفحص أيضًا مقابل: هل استخدم بيانات سلة حقيقية عند الحاجة بدل التخمين؟ هل بالأسلوب السعودي المعتمد؟ هل صعّد لموظف بشري عند الحاجة بدل الوعد بشيء لا يملك صلاحيته؟
